# Portfolio · Hugo Hernández

Web personal publicada en https://papasconalioli.github.io

## Páginas
- `index.html`: portada, sobre mí, investigación, congresos, publicaciones y documentos.
- `biografia.html`: experiencia, cursos, formación, habilidades y otros (mapa de viajes, música, galería).

## Archivos compartidos
- `assets/css/style.css`: estilos de las dos páginas (modo claro/oscuro incluido).
- `assets/js/main.js`: animaciones, idioma ES/EN, modo oscuro, mapa de viajes y aurícula interactiva.
  Los lugares del mapa están en la lista `PLACES` (y los países en `COUNTRIES`).

## Contenido
- `assets/foto-perfil.jpg`: foto principal (se recorta con la forma de la aurícula).
- `assets/galeria/1.jpg … 6.jpg`: galería (en la página de biografía).
- `assets/docs/`: TFG y TFM descargables.
- `assets/papers/`: artículos de congresos y miniaturas.
- `assets/map/`: capas de puntos del mapa del mundo.
- `extras/avatar-circulo.html`: avatar circular de reserva.

## Traducciones
Cada texto lleva el español como contenido y el inglés en el atributo `data-en`.

## Versiones guardadas (ramas)
- `version-una-pagina`: la web completa en una sola página.
- `version-circulo`: la web con el avatar circular.
